Cloud-Based Shopping List

A cloud-based shopping list web application that allows users to create, manage, and share shopping items in real time.

Features
User registration and login
Add, edit, and delete shopping items
Mark shopping items as completed
Search items by name or category
Category-based organization
Automatic total price calculation
Share individual shopping items with other users
Share complete shopping lists
View items shared by other users
Real-time data synchronization
Upload item images
Responsive interface for different devices

Technologies Used
React.js
Firebase Authentication
Firebase Firestore
Cloudinary
CSS
Vercel
Getting Started

1. Clone the repository
git clone https://github.com/surekha2119/Cloud-Based-Shopping-List.git

3. Open the project folder
cd Cloud-Based-Shopping-List

5. Install dependencies
npm install

7. Start the application
npm start

The application will run at:

http://localhost:3000
